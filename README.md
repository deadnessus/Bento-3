# Horizonte

City builder isométrico feito em HTML5 Canvas, sem dependências.

Abra `index.html` no navegador (celular ou computador) para jogar.

- Estradas, zonas residenciais, comerciais e industriais que crescem sozinhas
- Energia e água com alcance e capacidade, serviços (escola, hospital, polícia, bombeiros, praças)
- Valor do solo, poluição, demanda R/C/I, impostos e orçamento mensal
- Ciclo de dia e noite com luzes, carros, fumaça e sombras
- Salvamento automático no navegador

Controles: um dedo usa a ferramenta selecionada; dois dedos movem e dão zoom.
No computador: botão direito ou ferramenta "Mover" para arrastar, roda do mouse para zoom, WASD/setas, espaço pausa.

`game.html` é a fonte; rode `./build.sh` para gerar `index.html`.
